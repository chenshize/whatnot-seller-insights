# Whatnot Seller Insights

给面向美国市场的 Whatnot 卖家使用的中文情报 Skill。用户说一句“查查最近 Whatnot 有什么值得关注的变化”，Agent 查询公开信息，提供以信息为主、建议为辅的简报（不凑条数，只保留有依据、与当前经营相关且有新增价值的内容），并在本地保存通俗易懂的 HTML 完整报告，生成后由 Agent 自动打开。

## 安装

把下面这句话交给支持 Skill 安装的 Agent：

> 帮我安装这个仓库里的 whatnot-seller-insights Skill：https://github.com/chenshize/whatnot-seller-insights。安装后确认能读取 SKILL.md 和附带脚本，并告诉我如何调用。

Agent 应按自己的标准 Skill 安装机制安装整个目录，保留 scripts 和 references；不得把克隆成功当作已经注册成功。不同宿主是否支持安装、自动发现和脚本执行，需要在该宿主实际确认。如果宿主不支持 Skill，可读取 SKILL.md 按步骤执行，但这不等于安装完成。本项目不包含平台适配器或后台服务。

首次使用会一次询问可选的经营信息，回答或说“跳过”即可。例子：
- “帮我看看 Whatnot 最近有什么值得关注的变化。”
- “只查最近一周的运费和费用变化。”
- “继续查上次没查完的。”
- “展开第二条，给我看依据。”
- “更新画像：现在主要经营家居用品。”
- “清除这个工具保存的全部画像和查询记录。”

首次默认最近15天，以后按来源接着查。需要宿主已有联网和阅读能力；脚本需要 Python 3.10+，仅标准库。没有额外 AI API 费用、服务器或付费采集依赖，但宿主自己的额度和费用遵循该产品规则。

本地数据独立于仓库，详见 [操作说明](references/operations.md)。不登录店铺、不推送微信、不自动定时运行。图片/PDF按需生成。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

自动化测试检查日期连续性、未完成不推进、快照差异和失败恢复等逻辑。真实宿主安装与输出质量还应按 [验收场景](references/acceptance.md) 实测；不能保证网站和宿主功能永远不变。

信息源无法访问或执行步骤出错时，Agent 静默跳过并利用已获取的信息生成报告，不展示报错或要求配置 VPN；内部保留未完成来源，供下次补查。

报告采用具体标题和自然段落，按内容选择列表或比较表，不反复套用“发生了什么／和你有什么关系”栏目。原文链接就近附上，信息条件和证据仍保留。
