# 来源与证据

| 来源组 ID | 首选入口 | 用途与限制 |
|---|---|---|
| whatnot-help | https://help.whatnot.com/hc/en-us | 官方政策、费用、物流、工具、账户；脚本获取公开文章全集，Agent判断美国适用性 |
| whatnot-blog | https://blog.teamwhatnot.com/ | 官方活动及功能；美国栏目 https://blog.teamwhatnot.com/unitedstates ，可发现 RSS，但最新条目不代表完整历史 |
| seller-academy | https://selleracademy.whatnot.com/ | 官方经营资料，区分常青课程与新发布信息 |
| industry | https://www.valueaddedresource.net/tag/whatnot/ 、https://www.retaildive.com/ | 独立报道和行业变化；后者需筛选 Whatnot/直播电商/美国零售相关性 |
| seller-experience | 公开 Reddit r/whatnotapp、YouTube 卖家内容、https://blog.vendoo.co/ | 经验与线索；标注样本局限、商业立场，不当作普遍规律 |

结合 Whatnot、US、seller、fees、shipping、policy、update、live selling 及画像关键词检索。关注费用/收入、物流成本、账户风险、平台活动、工具、需求趋势及可验证的经营经验。不要无条件收录泛电商资讯。

来源组“完成”仅代表完成约定的入口与检索步骤，不代表穷尽整个网络。报告写明实际入口、检索词、翻页/归档范围、筛选规则。若只能拿到 RSS 最近若干项，需查归档或补搜；无法确认较早区间就保留待查。

官方帮助中心 API：
https://help.whatnot.com/api/v2/help_center/en-us/articles.json?per_page=100

接口说明：https://developer.zendesk.com/api-reference/help_center/help-center-api/articles/

脚本用正文与标题哈希发现快照之间的内容差异；updated_at 不能直接证明正文变化。首次仅依据 edited_at/created_at 提供候选，无法重建历史版本。当前抓到的正文可能在用户指定历史区间之后发生变化，应披露不能还原历史，不把当前版本冒充当时版本。实际生效日期从正文另行核实。官方源不可用时提供其他已核实信息，不用非官方经验替代正式政策结论。
